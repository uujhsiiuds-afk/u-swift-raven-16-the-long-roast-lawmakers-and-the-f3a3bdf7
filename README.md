One satirical sentence roasting the lawmakers who would regulate AI, crypto or the internet but cannot convert a file to PDF: the senator who just voted to regulate artificial intelligence emailed his office a Word file titled 'PLEASE MAKE THIS A PDF'. The program writes that sentence to /output/entry.txt and checks it against the competition gate (UTF-8, 1–320 characters, non-blank, single line).

## Run it

```sh
python3 main.py
```
